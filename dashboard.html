Panduan Install Manual:

💻 Pada Laptop / Desktop (Chrome, Edge, Brave):
Klik ikon Install yang berada di ujung kanan Kolom Alamat URL Browser Anda.
📱 Pada HP Android & iOS:
Klik tombol Titik Tiga (⋮) atau tombol Share (📤) pada browser HP Anda, lalu pilih 'Tambahkan ke Layar Utama' (Add to Home Screen).
