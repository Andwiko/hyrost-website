Jaminan Tanpa Penjualan Data:

Hyrost Realm TIDAK AKAN PERNAH menjual, menyewakan, atau memonetisasi data pribadi, alamat email, atau riwayat interaksi Anda kepada pihak ketiga pengiklan mana pun.

1

Komitmen Privasi Pengguna

Kebijakan Privasi ini menjelaskan bagaimana Hyrost Realm Network ("Kami") mengumpulkan, menggunakan, menyimpan, dan melindungi informasi pribadi Anda saat menggunakan website kami, bergabung dengan bot komunitas Discord (Bot Mei), atau mengakses server permainan Minecraft.

Kami berkomitmen mematuhi prinsip-prinsip perlindungan data yang ketat guna memastikan kenyamanan, keamanan, dan kebebasan berekspresi seluruh anggota komunitas kami.

2

Informasi yang Kami Kumpulkan

Kami hanya mengumpulkan informasi yang esensial untuk pengoperasian sistem dan autentikasi akun Anda:

  • Informasi Pendaftaran Akun: Username unik, alamat email aktif, dan kata sandi yang telah di-hash secara aman menggunakan algoritma Bcrypt dengan cost factor tinggi.
  • Data Akun Minecraft: Mojang In-Game Name (IGN), Minecraft UUID resmi atau offline, riwayat waktu bermain, level quest, inventaris in-game, dan saldo koin virtual.
  • Data Integrasi Discord (Bot Mei): Discord User ID, username tag, avatar, role server, dan status verifikasi guild.
  • Log Teknis & Keamanan: Alamat IP, user-agent browser, timestamp login, dan log aktivitas API untuk pencegahan spam, proteksi brute-force, dan mitigasi DDoS.
  • Data Transaksi Donasi: ID transaksi, nominal donasi, metode pembayaran yang dipilih (kami tidak menyimpan data kartu kredit atau PIN e-wallet Anda; seluruh pemrosesan dilakukan langsung oleh gateway berlisensi).
3

Bagaimana Kami Menggunakan Informasi Anda

Data yang terkumpul dimanfaatkan secara eksklusif untuk tujuan-tujuan berikut:

  • Mengautentikasi login Anda dan memverifikasi hak akses pada Dashboard, Forum, dan Toko Rank.
  • Menyinkronkan saldo koin, kosmetik, dan paket rank dari web ke server Minecraft secara instan melalui backend bridge.
  • Mengirimkan notifikasi penting seperti reset password, tiket bantuan support, pengumuman maintenance server, atau event giveaway.
  • Mendeteksi serta memblokir aksi kecurangan (anti-cheat log), multi-akun terlarang, dan upaya peretasan akun.
  • Menyajikan papan peringkat (Leaderboard) publik berupa statistik kompetitif game pemain.
4

Enkripsi, Penyimpanan, dan Keamanan Data

Kami menerapkan standar keamanan multi-lapis guna memastikan data Anda terlindungi dari kebocoran maupun akses tanpa hak:

Prinsip Zero-Knowledge Password:

Kata sandi Anda tidak pernah disimpan dalam bentuk teks biasa (plain-text). Tim staf maupun admin Hyrost tidak dapat melihat kata sandi asli Anda.

  • Enkripsi Password: Password dienkripsi satu arah menggunakan modul Bcrypt salt rounds.
  • Otorisasi Token: Sesi pengguna dilindungi menggunakan JSON Web Token (JWT) terenkripsi dengan masa kedaluwarsa otomatis.
  • Enkripsi Transit (HTTPS/TLS): Seluruh pertukaran data antara browser Anda dan server kami dienkripsi menggunakan protokol TLS 1.3 / SSL 256-bit.
  • Isolasi Database: Server database MySQL berjalan di lingkungan terisolasi di balik firewall internal dan dilindungi backup otomatis berkala.
5

Integrasi dan Layanan Pihak Ketiga

Untuk menyajikan fungsionalitas optimal, kami berinteraksi dengan API pihak ketiga yang tepercaya:

  • Google OAuth: Memfasilitasi pendaftaran dan login cepat dengan akun Google. Kami hanya menerima email dan nama profil publik Anda.
  • Mojang / Crafatar API: Menampilkan skin karakter dan kepala 3D Minecraft berdasarkan username publik Anda.
  • Discord API: Digunakan oleh Bot Mei untuk sinkronisasi role komunitas dan verifikasi ID member Discord.
  • Payment Gateway: Memproses konfirmasi transaksi secara otomatis melalui webhook terenkripsi tanpa menyimpan informasi kredensial perbankan Anda.
6

Cookie dan Penyimpanan Lokal (Local Storage)

Website kami menggunakan cookie dan browser localStorage untuk kebutuhan fungsional esensial:

  • Token Sesi: Menyimpan token autentikasi login sehingga Anda tidak perlu login berulang kali di setiap pergantian halaman.
  • Preferensi Pengguna: Mengingat pengaturan tema tampilan gelap (dark mode), volume audio player, dan status notifikasi.
  • Kami tidak menyematkan cookie pelacak periklanan pihak ketiga (third-party tracking cookies).
7

Hak dan Kontrol Pengguna atas Data

Anda memiliki kendali penuh atas data pribadi Anda dalam platform kami:

  • Hak Akses & Pembaruan: Anda dapat meninjau dan mengubah informasi profil, email, maupun password kapan saja di halaman Pengaturan Akun.
  • Hak Penghapusan (Right to be Forgotten): Anda berhak mengajukan permohonan penutupan akun dan penghapusan data identitas permanen melalui tiket bantuan staf.
  • Hak Pelepasan Tautan Akun: Anda dapat memutuskan tautan Discord atau Minecraft dari akun web Anda sewaktu-waktu.
8

Perlindungan Privasi Pengguna di Bawah Umur

Layanan kami ditujukan untuk komunitas pemain umum. Kami tidak secara sengaja mengumpulkan data pribadi sensitif dari anak-anak di bawah usia 13 tahun tanpa persetujuan orang tua atau wali hukum.

Jika orang tua atau wali mendapati bahwa anak mereka telah memberikan data pribadi tanpa persetujuan, silakan hubungi tim kami untuk segera kami tindak lanjuti dan hapus dari sistem.

9
